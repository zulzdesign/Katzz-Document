Katzz - Readme

A Grasshopper plugin for advanced, custom wiring workflows inside Rhino 8. Developed by Bidezzign Limited.

← Legal Center

🚀 Key Features

Select Wires: Main feature of the plugin, allows you to select wires.

Customize Wires: Enhanced navigation of complex wire by higlighting wires.

Top-Level UI Interface: Access controls directly through a custom Windows-native interface.

Performance Focused: Built using optimized C# assemblies for instant execution.

📦 Installation & Activation

  1. Open Rhino 8.
  2. Type PackageManager into the command line and press Enter.
  3. Search for Katzz.
  4. Click Install and restart Rhino.
  5. Open the Katzz license activation panel from the Rhino top menu. (The store link to the product checkout page is located directly inside this interface).
  6. Purchase the Licensing key from Lemon Squeezy (our 3rd-party marketplace provider). You will receive a free 7-day trial for $0.00.
  7. Enter and activate your license key from Lemon Squeezy to unlock full plugin access.
